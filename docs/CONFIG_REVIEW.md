# Offline configuration review

`versionsec config review --snapshot snapshot.json --policy private --format json`

Input must be an explicitly selected, anonymized JSON snapshot matching
`forgeguard.config-snapshot.v1`. See the packaged schema and
[synthetic Gitea](../examples/gitea-snapshot.json) /
[synthetic Forgejo](../examples/forgejo-snapshot.json) fixtures.
Use an alias, not a production hostname. Never supply raw app.ini, environment
dumps, keys, SMTP/OAuth credentials or databases.

The command performs zero network requests, does not discover configuration, and
does not verify what a running process loaded. All findings refer to the supplied
snapshot. Reports do not assert authorization to a running server.

The closed key list is generated by `versionsec providers`.
Both products support the reviewed service registration/confirmation/sign-in
keys and repository default/forced privacy keys. Gitea's reviewed MFA key is
`security.TWO_FACTOR_AUTH` (empty or enforced). Forgejo's is
`security.GLOBAL_TWO_FACTOR_REQUIREMENT` (none, admin or all).
Product/version-specific sources and hashes are in [UPSTREAM](UPSTREAM.md).

Missing keys remain unknown. An operator may explicitly enumerate keys in
`declared_defaults`; only a qualified exact version permits the documented
defaults to be applied. A key cannot have both an explicit value and a default
declaration. Unknown fields, foreign-product keys, wrong types and invalid values
are refused without echoing the rejected input.

Snapshots older than 30 days or from the future remain incomplete. Timestamps
must contain a timezone. Optional `--product` declares the expected product and
a mismatch makes review incomplete. Concurrent email and manual registration
confirmation is a conflict under the reviewed upstream semantics.

Private policy expects closed registration, required sign-in, forced privacy for
new repositories and MFA for all. Public and unspecified intent expose declared
settings as informational observations. Default private creation is not forced
privacy and says nothing about existing repositories. MFA configuration does not
prove completed enrollment or any particular user's MFA state.
