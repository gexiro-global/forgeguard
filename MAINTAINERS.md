# Maintainers

| Maintainer | Roles | Contact |
|---|---|---|
| `@dzeusking-dev` | project owner, release maintainer, security contact | [GitHub](https://github.com/dzeusking-dev) |

One person holds every role. That is disclosed deliberately: it means there is
no independent review of changes and no response-time guarantee. See
[docs/REVIEW.md](docs/REVIEW.md) for what the automated gates compensate for and
what they do not, and [GOVERNANCE.md](GOVERNANCE.md) for how decisions are made.

The project is owned by Gexiro Global Enterprises Ltd, so continuity of the
published packages and the repository does not depend on a single personal
account.

Security reports must use [SECURITY.md](SECURITY.md), not public issues.
